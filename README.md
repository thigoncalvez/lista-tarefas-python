# Lista de Tarefas

Projeto desenvolvido em Python durante meus estudos iniciais de programação.

## Sobre o projeto

Aplicação simples de lista de tarefas executada pelo terminal.

O usuário pode inserir tarefas, apagar tarefas e visualizar os itens cadastrados.

## Tecnologias utilizadas

- Python

## Conceitos praticados

- Listas
- `while`
- `if / elif / else`
- `input()`
- `append()`
- `del`
- `enumerate()`
- `try / except`
- Tratamento de `ValueError`
- Tratamento de `IndexError`

## Objetivo

Este projeto foi desenvolvido para praticar estruturas de dados, estruturas de repetição, menus interativos e tratamento de erros em Python.

Esta é a primeira versão do projeto e representa meu nível de conhecimento durante seu desenvolvimento.
